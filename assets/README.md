# 素材来源

- `source-food/`：用户提供的四张菜品原照片，保留原件。
- `generated/`：蜡笔纹理、三只静态食材小怪兽，以及各轮菜品海报和简洁菜单图片的生成原件。当前海报使用 `*-poster-poses-v3.png`，菜单图片使用 `*-menu-clean.png`；它们包含背景整理与器皿补全，不等同于未经编辑的原照片。
- `fonts/`：Google Fonts Long Cang 字体、OFL 授权与页面字形子集。

小程序目录只保存优化后的交付文件。字体和蜡笔背景已内嵌到 WXSS，避免依赖远程字体或不受支持的本地背景路径。未加入任何喜茶官方标识。
