## 设计依据

保留现有首页进入菜单、菜单左侧分类、菜品列表、添加按钮及购物袋入口的主要结构。画风来自真实食物摄影与粗黑手绘小人的互动：食物保留材质，小人通过搬叶子、攀锅沿、搅拌等动作讲述微型故事。

页面大面积使用奶油白 #FFF7E8；番石榴绿 #A8C978 用于主要按钮和选中状态；果肉粉 #F28C8C 用于推荐标记、添加按钮和数量徽标；深叶绿 #527A4B 用于界面文字与图标；黑色保留给手绘角色与艺术标题。自然菜品颜色不受这四个品牌色限制。

艺术标题允许不规则笔触，菜名、说明、金额与导航保持规整可读。菜单左侧分类延续现有页面结构。图中的中文菜名取自参考聊天；人民币价格仅用于演示信息层级，不代表实际定价。首页「我的」与搜索等入口在原项目中尚未形成完整业务，设计展示不等于功能已实现。

## 后续照片一致性建议

以保留真实菜品为前提：统一裁切尺度与视角、轻调白平衡和曝光、去除杂乱背景、配统一奶油底与少量接触阴影。不要用重滤镜改变熟度、食材颜色与份量，也不要重新生成菜品替代原菜。本轮首页参照原海报，其他菜品仅为概念示意，不承诺与原菜照片逐像素一致。

每张主视觉最多安排一到两个可读的涂鸦动作。菜单缩略图进一步减少细节，以免影响识别和点单。未来可以变化小人动作与构图，但保持线条、背景、排版及配色规则稳定。

## 审阅重点

1. 摄影与手绘的比例、整体留白是否接近期望。
2. 番石榴绿与果肉粉的使用量是否合适。
3. 首页的海报感与菜单的信息密度是否平衡。

确认设计方向后再进入代码实现。
