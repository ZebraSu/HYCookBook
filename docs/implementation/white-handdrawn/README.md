# 白底手绘版

按用户反馈，将页面、原生导航栏、底部导航和清单底栏统一改为白色。分类按用户最新要求恢复为左侧纵列、右侧菜品列表，两侧独立滚动；保留 16/14px 功能文字、绿粉配色和原有菜品数据。

主要按钮使用不规则双线描边与两侧的浅色蜡笔划痕，中间文字区域保持清楚。分类选中项和“查看已选”沿用手绘按钮表达；加减按钮恢复不规则圆形描边。首页增加手写标题下划线和粉色推荐标签。

原有角色 JPG 带奶油底，本轮以不规则圆形纸贴背景承接，避免在白底上露出方形底色，没有重新生成角色。

仅视觉和应用背景配置变更，不改变选菜、保存与路由逻辑。已检查本地资源与语法，并对四页及两个组件运行原生样式编译。本轮未进行手机真机验收。

左右布局更新：菜单页 WXML/WXSS 原生编译通过，分类按钮保持 60×52px，小屏右侧缩小照片以保留文字和加减控件宽度。
