# 首页菜品海报轮播

首页改为四张完整显示的海报，430px 模拟器中轮播高度420px；窄屏随宽度缩放，短屏上限280px。每6秒切换，左右滑动或点击44px圆点按钮后暂停，离开页面停止自动播放。菜名、口味及选菜入口放在轮播下方。

新增牛肉烧豆腐，归入招牌和家常，使用用户原照片作为菜单图片。现有三道菜及新菜均配置独立海报。三张新海报沿用已确认的细笔手写字、白底、完整餐盘及微型人物；源照片未拍全的餐盘边缘由图像生成补全。海报源文件保留在 assets/generated，原照片保留在 assets/source-food。

新菜尚无获用户确认的小怪兽，角色收藏仅展示已有角色。海报目录已显式加入项目打包规则；本地资源检查同时核对目录是否被排除。

验证：
- 13项本地测试通过：搜索、数量、清单保存、返回路由、轮播状态和资源检查。
- 首页WXML/WXSS原生编译通过。
- iPhone15ProMax（430×932）模拟器确认自动轮播、圆点切换与暂停、选菜入口、豆腐搜索、新菜加入和保存。
- 新菜通过数量组件的change事件加入、在清单确认，再移除；最终存储仍为用户原先的一份肉饼。
- 打包前源文件约1701KiB，未进行手机真机预览或发布。
