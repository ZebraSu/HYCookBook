# 克制手绘版

本轮根据审美评审调整四个原生页面。保留奶油底色、绿粉配色、真实照片和小怪兽；功能文字使用系统字体，手写仅用于首页主标题和个人页角色标题。

- 菜品分类改为横排，释放菜名与照片的横向空间。
- 正文 16px、辅助文字 14px，避免随小屏进一步缩小；辅助文字颜色加深。
- 去除控件内部的蜡笔噪点，统一颜色、字号、圆角等共享变量。
- 列表照片使用统一方形圆角框；首页推荐保持照片完整比例。原照片本身是近景，本轮没有生成或伪造完整器皿。
- 用“菜品”表示浏览入口、“查看已选”表示当前清单，说明本地保存与复制用途。
- 个人页突出当前清单，将三只角色集中展示。

历史截图在 ../native/，本目录为优化后的微信模拟器截图。真机、辅助技术和系统剪贴板实际写入不在本轮验证范围内。

## 验证

- 12 项逻辑测试通过，包含个人页空清单直接进入选菜的路径。
- 四页与两个组件的 12 项 WXML/WXSS 编译通过；底栏选中样式最终调整后另行编译通过。
- 11 项小屏原生交互断言通过，含实际点击加号、横排分类、跨分类搜索、空结果重置、清单返回及个人页有/无菜品的不同入口。
- 320px 模拟器实测分类按钮 69×44px，菜品说明 14px。小屏首页主按钮与列表末尾通过滚动可到达。
- 共享文字颜色组合对比度检查通过；说明文字对纸色为 5.87:1，对搜索框为 5.40:1。绿色按钮文字 4.53:1。
- 验证期间遇到一次开发者工具页面状态异常，重启后恢复；最终运行日志检查没有发现业务错误。
- 已移除测试菜品，恢复空清单和 iPhone 12/13 Pro 模拟器首页。
